# mailer/ — INSTA-EBASHER рассылка (скриптовая версия)

Автономный движок первой Instagram-рассылки. Работает через обычный Chrome (отдельное окно-профиль), без прокси/антидетекта/cookie. Всем управляет агент (Codex/Pi) по мануалу.

## С чего начать

- **Вы клиент?** → `START_FOR_CLIENT_RU.md` (4 шага: распаковать, Node, start-chrome.bat, один промпт агенту)
- **Вы агент?** → `AGENT_MANUAL_RU.md` (установка, команды, ошибки, правила)
- **Сценарии работы** → `docs/USECASES_CLIENT_RU.md`

## Ключевые факты

- Одно первое сообщение на человека, без повторов; отписка навсегда; лимит 35/день встроен
- Человеческий темп: паузы 3–6 минут между DM, посимвольная печать, мини-чат
- Нет кнопки Message у получателя → пропуск (не обходится)
- Каждый шаг пишет evidence-скриншоты (`state/evidence/`)
- Тесты: `npm test` (150 штук)
