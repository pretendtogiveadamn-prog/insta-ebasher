# USECASES_CLIENT_RU.md — симуляция взаимодействия клиент ↔ агент (INSTA-EBASHER v2)

Каждый юзкейс: что говорит клиент → что делает агент (точные команды) → что происходит в системе/окне → что агент отвечает.
Метки: ✅ = проверено вживую 2026-09-25, 🧪 = покрыто тестами, 📖 = поведение по коду/мануалу.

---

## UC-1. Первый запуск ✅🧪

**Клиент:** распаковал ZIP, поставил Node, двойной клик `start-chrome.bat`, залогинился в IG, вставил стартовый промпт агенту.

**Агент:**
```bash
npm install                 # ~20 сек, 3 пакета, без скачивания браузеров ✅
node run.mjs doctor         # ✔ chrome cdp alive, ✔ sqlite ✅ (чистая комната проверена)
node run.mjs dood           # PHASE 0 GATE: GREEN ✅
node run.mjs accounts add --anty-profile local-chrome --username @клиент --cap 35   # ✅
```

**Агент клиенту:** «Всё готово: Chrome вижу, база создана, тесты зелёные. Кидай список хэндлов и текст — сначала сделаю одну репетицию без отправки, посмотришь, потом поедем по-настоящему».

## UC-2. Заведение лидов ✅

**Клиент:** «Добавь @anna.beats и @prod_xv. Текст: yo {handle}, heard ur stuff — got a beat pack for u, want me to send?»

**Агент:**
```bash
node run.mjs leads add --handle anna.beats --draft "yo {handle}, heard ur stuff — got a beat pack for u, want me to send?"   # ✅
node run.mjs leads add --handle prod_xv --draft "..."                                                                       # ✅
node run.mjs leads status anna.beats --value ready && node run.mjs leads status prod_xv --value ready                       # ✅
node run.mjs leads list   # показывает [ready], draft ✔ ✅
```

**Агент клиенту:** «Два лида готовы. Текст подставит @хэндл каждому сам. Гоняю репетицию на первом — 2 минуты».

## UC-3. Dry-run (репетиция) ✅

**Агент:** `node run.mjs send --lead-id <id8> --dry-run`

**В окне Chrome (клиент смотрит):** открывается профиль anna.beats → пауза-«чтение» → клик Message → справа внизу мини-чат → текст **печатается посимвольно** → стоп, не отправляется → чат закрывается. ✅ (всё это видели вживую)

**Агент:** `node run.mjs evidence <id8>` → открывает скриншот `S7_dry_run_stop` → «Смотри: текст напечатан в чате с @anna.beats, не отправлен. Запускаем по-настоящему?»

**Клиент:** «да».

## UC-4. Live-отправка пачкой ✅

**Агент:** `$env:IH_CLASSIFY_ONLY="0"; node run.mjs send --account <acc8>`

**В окне:** по очереди каждый лид: профиль → Message → печать → Enter → пузырь в чате → чат закрыт → главная → **пауза 3–6 мин** (тихо, без дерганий) → следующий. ✅ (4 реальные отправки сегодня)

**Система:** после каждого — жёсткое подтверждение (пузырь в DOM/сеть), запись в лог, evidence-скриншоты каждого шага. ✅

**Агент клиенту (когда батч кончился):** `node run.mjs stats` → «Отправил 2 из 2. Следующая пачка — когда скажешь (лимит 35/день)».

## UC-5. У получателя нет кнопки Message ✅

**Система:** профиль открыт, кнопки нет → лид `failed_exact`, **без попыток обойти**, кд ~2 мин → следующий. ✅ (сценарий 22k_dooter отыгран)

**Агент клиенту:** «@prod_xv пропустил — у него закрыты входящие (нет кнопки Message). Это нормально, идём дальше. Остальные отправлены».

---

## UC-6. Клиент закрыл окно Chrome посреди батча 🧪

**Система:** текущий лид → `needs_manual` (НЕ пересылается автоматом — анти-дубль), батч останавливается событием `attach_failed`/`batch_tab_lost`, остальные лиды **остаются ready — не сгорают**. 🧪 (код: scheduler пере-attach + break)

**Агент клиенту:** «Окно закрылось — всё остановилось безопасно, никто не получил двойного. Открой снова `start-chrome.bat`, скажи — продолжу с того же места». Перезапуск: батч берёт первого ready — того самого. 📖

## UC-7. «Стоп» посреди батча 📖

**Клиент:** «останови».

**Агент:** прерывает выполнение команды (останавливает процесс). Уже отправленное — записано; неотправленные остаются ready.

**Агент клиенту:** «Остановил. Ушло 2 из 5, остальные в очереди — скажешь «погнали» — продолжу».

## UC-9. «Понятно ли, отправилось ли?» / сомнительный исход ✅

**Система:** если после Enter не увидела пузырь за 15 сек → `uncertain`, **без повторов**. ✅ (случилось вживую 2 раза — оба раза пузырь на самом деле был)

**Агент:** `node run.mjs evidence <id8>` → смотрит последний скриншот глазами → пузырь есть → `leads status <h> --value sent` → клиенту: «Отправлено, вот скрин». Пузыря нет → перезапуск этого лида вручную. ✅ (механика подтверждения после этого усилена — скелетный матч, live-проверено)

## UC-11. Капча / блок 📖🧪

**Система:** капча → СТОП всего + evidence; action-block → аккаунт в кд 4ч (эскалация 24/72ч). 🧪

## UC-12. «Кто-нибудь ответил?» 📖 (честный gap)

**Система:** v2 не читает входящие (только отправляет). Ответы — в том же окне Chrome, раздел Direct.

**Агент клиенту:** «Отправки все записаны, а ответы посмотри в окне рассылки — колокольчик Direct сверху. Если надо — могу открыть и пересказать, что там». *(Чтение входящих — кандидат в v2.1, в v1 это был inbox-lease.)*
