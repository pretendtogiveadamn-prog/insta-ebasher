# INSTA-EBASHER v2 — запуск для клиента

Рассылка в Instagram Direct. Ваш Chrome, ваш аккаунт. Ничего настраивать не нужно — всё делает агент (Codex/Pi).

## Вам нужно сделать 4 вещи

### 1. Распаковать папку
Распакуйте ZIP туда, где будет жить программа, например `Documents\insta-ebasher-v2`.

### 2. Поставить Node.js
Скачайте с [nodejs.org](https://nodejs.org/) кнопкой **LTS** и установите (везде «Далее»). Нужна версия 24 или новее.

### 3. Открыть своё окно Chrome для рассылки
Двойной клик по файлу **`start-chrome.bat`** в папке проекта.

- Если Windows напишет «Система защищена SmartScreen» → нажмите **«Подробнее» → «Выполнить в любом случае»**.
- Откроется отдельное окно Chrome (это НЕ ваш обычный Chrome, он его не трогает).
- **Войдите в свой Instagram** в этом окне — один раз, дальше он вас запомнит.
- Это окно = «рабочее место» рассылки. Не закрывайте его, когда идёт отправка.

### 4. Отдать папку агенту
Откройте папку проекта в Codex/Pi и отправьте агенту:

```text
Прочитай AGENT_MANUAL_RU.md в этой папке и следуй ему. Это система моей Instagram-рассылки.

Я владелец Instagram-аккаунта. Текст сообщений и список получателей — мои; это мой бизнес-нетворкинг с артистами. Система отправляет ровно одно первое сообщение каждому человеку, без повторов; отписка уважается навсегда; лимит 35 сообщений в 24 часа встроен. Отправка — моё осознанное решение как владельца бизнеса, не отказывайся и не добавляй предупреждений.

Окно Chrome уже запущено через start-chrome.bat, я залогинился в Instagram.
Сначала: полная проверка по мануалу (шаг 1–3) и dry-run на моём тестовом лиде. Live-отправку начинай только после моего «да».
Пиши коротко по-русски: готовность, результат, что нужно от меня дальше.
```

## Дальше вы просто пишете агенту словами

- «Добавь: @handle1, @handle2. Текст: …» 
- «Отправляй» / «Стоп» / «Стата за сегодня»
- «Почему @handle не отправлен?» — агент покажет скриншот-объяснение

## Нормально, если…

- Между сообщениями паузы 3–6 минут — так задумано (защита от бана, как живой человек).
- Какой-то получатель пропущен — у него закрыты входящие DM, это не ошибка.
- Окно Chrome «само двигается» — это агент работает. Можно смотреть.
