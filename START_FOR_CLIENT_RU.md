# INSTA-EBASHER — запуск для клиента

Это локальная система для поиска артистов, первой Instagram-рассылки и фиксации ответов. Она работает через ваш обычный уже залогиненный Chrome и Codex. Никаких прокси, cookie-файлов и отдельных браузеров здесь нет.

## Первый запуск

1. Откройте страницу проекта на GitHub и нажмите **Code → Download ZIP**.
2. Распакуйте ZIP в удобную папку, например `Documents\insta-ebasher`.
3. Установите Node.js 20 LTS, если его ещё нет: [nodejs.org](https://nodejs.org/).
4. Откройте распакованную папку как проект в Codex.
5. Откройте обычный Chrome, войдите в нужный Instagram-аккаунт и подключите эту вкладку к Codex Chrome MCP.
6. Отправьте Codex следующий текст целиком.

## Текст для первого сообщения Codex

```text
Скачай и подготовь к работе INSTA-EBASHER из этого репозитория:
https://github.com/pretendtogiveadamn-prog/insta-ebasher

Работай по файлу `prompts/client-onboarding-agent.md` из репозитория. Выполни установку, `npm run check`, запуск панели и проверку health endpoint. Не перезаписывай существующие папки и не меняй код без запроса.

Когда локальная панель готова, попроси меня только открыть нужный уже залогиненный Instagram в обычном Chrome и подключить вкладку к Codex Chrome MCP. Не используй прокси, антидетект, cookie-файлы, автологин, отдельный браузер или Playwright.

После подключения спроси меня одним сообщением:
«Кого ищем, сколько артистов нужно, у каких продюсеров искать и какие критерии важны?»

Не начинай ресерч или рассылку без моего явного задания. Пиши коротко по-русски: готовность, результат, что нужно от меня дальше.
```

## Как пользоваться дальше

Пишите Codex обычными словами:

- «Найди артистов» — он сам спросит, у каких продюсеров искать и сколько нужно.
- «Покажи, кого нашёл» — покажет карточки и статусы в панели.
- «Вот текст: … Запускай рассылку» — создаст кампанию и начнёт последовательную отправку в пределах лимита.
- «Проверь входящие» — зафиксирует новые ответы, контакты и отказы.
- «Останови всё» — остановит кампанию; никакие новые DM не будут выданы.

## Что важно

- Для первого реального запуска сначала сделайте dry-run, затем одну тестовую отправку на свой аккаунт.
- Панель доступна локально на `http://127.0.0.1:3100/`, пока Codex запустил систему.
- Telegram-уведомления необязательны. Если они нужны, попросите Codex настроить их через локальный `.env`; не отправляйте токены в чат.
